ℹ️ About Morning Agent
Why

Everything you need in the morning — in one email

No app to open, no scrolling through notes. Set it once and get it ready-made.

🖥️

Lives in the menu bar

A light ☀︎ icon next to the clock. No windows, no Dock — native via rumps.

🧠

Any model

Via OpenRouter: Claude, GPT, Llama… Just type the model slug and you're done.

📂

From your notes

Reads .md/.txt files from a folder you pick — Obsidian, Bear, anything.

📰

Blogs & newsletters

Add RSS/Atom feeds and the latest posts land in your morning mail.

✍️

Your prompt

You define the instruction the model gets each morning, right from the menu.

📨

Email via Resend

Clean HTML, reliable delivery. Straight to your inbox at a set time.

🔒

Keys stay local

Everything in ~/.config — never in the repo, never in the cloud.

How it works

Four steps, zero effort in the morning

At a set time the app does everything on its own.

1

Reads notes & feeds

Scans your .md/.txt folder and RSS feeds.→

2

Asks the model

OpenRouter composes the briefing from your prompt.→

3

Builds the email

A clean HTML with today's sections.→

4

Sends it

Resend delivers it to your inbox. 📬

Up in 2 minutes

Install and configure

One command, a few fields in the menu — and you're set.

  1. 1
    Install
    brew install rafalgawlik/tap/morning-agent
  2. 2
    Run
    morning-agent — the ☀︎ icon appears
  3. 3
    Enter your keys
    Resend + OpenRouter in the menu → Settings
  4. 4
    Add notes, feeds and prompt
    a notes folder, RSS feeds, and your morning instruction
  5. 5
    Turn on auto-deliver
    a time + brew services start morning-agent
